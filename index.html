Project Overview **NetworkLab Arena** is an open-source, lightweight 2D multiplayer experimental testbed designed to investigate how network latency, jitter, and packet loss affect hit registration and competitive fairness in real-time shooter games. The project compares two server-side hit-registration approaches under controlled network conditions. - **Technology stack:** Node.js, WebSockets,
